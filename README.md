## ✨ 핵심 특징

1. **100% 무료 운영 (Zero Costs)**
   - **Vercel Hosting**: 평생 무료 SSL(HTTPS) 웹 호스팅 (`https://thaicall.vercel.app`)
   - **WebRTC (PeerJS)**: 중앙 서버 없는 P2P 초고속 자막 전송
   - **Gemini AI 고품질 번역**: 내장된 고품질 AI 번역 엔진으로 매끄러운 20개국 대화체 번역 지원

2. **간편한 1-Click 접속**
   - 방 생성 시 **6자리 회의 코드** 및 **QR 코드** 자동 생성
   - 초대 링크나 QR 코드를 스캔하면 상대방 화면 언어에 맞게 자동 맞춤 설정

3. **다국어 스마트 UI (i18n)**
   - 언어 검색 및 선택 시 **첫 화면부터 전체 UI 버튼이 해당 언어로 동적 변경**
   - 기기 브라우저 언어 자동 감지 지원
